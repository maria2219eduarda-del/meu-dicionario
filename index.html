Dicionário de Dados - Sistema de Gerenciamento para Salão de BelezaFátima Aparecida de Lima Cabeleireira

Identificação do projeto

Escopo
Banco de dados de apoio à operação e às finanças do salão Fátima Aparecida de Lima Cabeleireira: cadastro de clientes e fichas capilares, catálogo de serviços e insumos, agenda sem conflitos, atendimentos, pagamentos, despesas, fechamento de caixa, controle de estoque, controle de acesso (RBAC) e trilha de auditoria, normalizado até a 3ª Forma Normal.
Tecnologia
MySQL 8.0 (InnoDB, utf8mb4).
Professor orientador
Prof. Dr. Diego Marques de Carvalho (UNICID - Modelagem de Banco de Dados)

Responsáveis (Data Owners e Data Stewards)

IntegrantePapel e responsabilidade
Data Owner: responde pelas regras de negócio dos dados. Data Steward: responde pela qualidade técnica e pelo dicionário. RBAC: ADM = Administrador; ATD = Atendente; SIS = Sistema (aplicação). C = criar, R = ler, U = atualizar. Não há exclusão física (D).
